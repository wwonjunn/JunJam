# Your Jun Jam library

Jun Jam keeps your own work here as files, so nothing important lives only inside the browser:

- `transcriptions/`: one folder per transcription (score.json, chords.txt, the recording, reading.json)
- `licks.json`: your own licks
- `progress.json`: everything else Jun Jam remembers (stars, reviews, Gig charts, routines, settings)
- `backups/`, `deleted/`: copies kept before a restore, and transcriptions you deleted

To link it: in Jun Jam press Save on a transcription (or Profile & settings → Your files), and in the folder window
choose this `library` folder and press Select.

Everything here except this README is ignored by git. Delete the rest before sharing Jun Jam.
